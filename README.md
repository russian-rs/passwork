# Passwork – Командное хранилище секретов 🔐

Passwork — это современное, защищенное веб-приложение для безопасного хранения и обмена паролями, 2FA-кодами (TOTP) и конфиденциальными заметками внутри команды.

Приложение обладает потрясающим интерфейсом с эффектами "Glassmorphism", плавной анимацией и поддержкой нескольких языков (Русский, Английский, Сербский).

## ✨ Основные возможности

- **Хранилище учетных данных:** Безопасное хранение логинов, паролей, адресов сайтов и секретных заметок.
- **Встроенный 2FA (TOTP):** Автоматическая генерация одноразовых паролей для двухфакторной аутентификации прямо в карточке секрета (больше не нужен Google Authenticator на телефоне).
- **Категоризация:** Группировка доступов по категориям с возможностью быстрого поиска.
- **Одноразовые ссылки (Burn-after-reading):** Возможность поделиться паролем с внешними людьми через защищенную ссылку. Как только секрет будет прочитан, он навсегда удалится из базы данных.
- **Автоматическая очистка:** Встроенный распределенный планировщик, который сам удаляет просроченные непрочитанные ссылки раз в 15 минут.
- **SSO Аутентификация:** Интеграция с корпоративным провайдером **Authentik** (на базе NextAuth v5).
- **Мультиязычность:** Полный перевод интерфейса на 3 языка без перезагрузки страницы (сохраняется локально).

## 🛠 Технологический стек

- **Frontend:** Next.js 16+ (App Router), React 19, Tailwind CSS v4, Lucide React, Framer Motion.
- **Backend:** Next.js Server Actions, Drizzle ORM, PostgreSQL.
- **Авторизация:** NextAuth.js (v5 Beta) + Authentik Provider.

## 🚀 Как запустить локально

### 1. Требования
- Установленный Node.js (рекомендуется v20+)
- Запущенная база данных PostgreSQL
- Настроенный сервер Authentik (для авторизации)

### 2. Установка зависимостей

Склонируйте репозиторий и установите пакеты:

```bash
npm install
# или
yarn install
```

### 3. Настройка переменных окружения

Создайте файл `.env.local` в корне проекта и заполните его по аналогии:

```env
# Строка подключения к PostgreSQL
DATABASE_URL="postgres://user:password@localhost:5432/passwork"

# Настройки NextAuth (сгенерируйте секрет командой: npx auth secret)
AUTH_SECRET="ваша-секретная-строка"
AUTH_URL="http://localhost:3000"

# Настройки Authentik SSO
AUTHENTIK_CLIENT_ID="ваш-client-id"
AUTHENTIK_CLIENT_SECRET="ваш-client-secret"
AUTHENTIK_ISSUER="https://auth.example.com/application/o/passwork/"
```

### 4. Запуск проекта

В проекте настроены **автоматические миграции** при старте приложения (через файл `instrumentation.ts`). Вам не нужно запускать их вручную! 

Для режима разработки:
```bash
npm run dev
```

Для сборки и запуска в production-режиме:
```bash
npm run build
npm start
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).
